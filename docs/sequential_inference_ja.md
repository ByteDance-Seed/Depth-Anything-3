# V3 がフレーム間の情報をどのように使うか

## 概要

Depth Anything V3（DA3）は、複数フレームを**一度に**モデルへ渡すことで、フレーム間の相互情報を活用した深度・カメラ姿勢推定を行う。
従来のモノキュラー深度推定（V2 など）が 1 枚ずつ独立して処理するのと異なり、**同一 `inference()` 呼び出し内のフレームは互いに参照し合う**。

---

## アーキテクチャの仕組み：Local / Global Attention の交互適用

バックボーンは DINOv2 ベースの Vision Transformer（ViT）であり、後半のレイヤーから **Local attention** と **Global attention** を交互に適用する。

```
入力テンソル形状: (B, N, 3, H, W)
  B = バッチサイズ
  N = フレーム数（シーケンス長）
```

### Local Attention（前半レイヤー、および偶数番レイヤー）

```python
x = rearrange(x, "b s n c -> (b s) n c")
x = block(x)  # 各フレームが独立してattentionを計算
x = rearrange(x, "(b s) n c -> b s n c", b=B, s=S)
```

- 各フレームのパッチトークンが**そのフレーム内のみ**で自己注意を計算する
- フレーム間の情報交換はない

### Global Attention（`alt_start` 以降の奇数番レイヤー）

```python
x = rearrange(x, "b s n c -> b (s n) c")
x = block(x)  # 全フレームのトークンをまとめてattentionを計算
x = rearrange(x, "b (s n) c -> b s n c", b=B, s=S)
```

- 全フレームのパッチトークンを**一つの系列に結合**して attention を計算する
- あるフレームのトークンが、他のすべてのフレームのトークンを参照できる
- これにより深度スケールやカメラ姿勢が**フレーム間で整合**する

### 参照ビューの選択（`alt_start - 1` 番レイヤー）

Global attention 開始直前に、N フレームの中から**基準フレーム**を 1 枚選択する（`THRESH_FOR_REF_SELECTION = 3` フレーム以上のとき）。  
基準フレームには `ref camera_token`、残りには `src camera_token` が `CLS` トークン位置に埋め込まれ、モデルにビューの役割（基準 vs 参照元）を伝える。

---

## 同一 `inference()` 呼び出しで得られるもの

| 出力 | 内容 |
|------|------|
| `depth` | 全フレームで**スケール整合**した深度マップ |
| `depth_conf` | 各ピクセルの深度信頼度 |
| `extrinsics` | 全フレームの**共通座標系**でのカメラ外部パラメータ（姿勢） |
| `intrinsics` | 各フレームのカメラ内部パラメータ |

フレームを一括で渡す限り、スケールの一貫性は推定時間に関係なく保証される。

---

## バッチを分けた場合の注意（スケールドリフト）

`process_video_batch.py` のようにフレームをチャンクに分けて複数回 `inference()` を呼ぶと、**各呼び出しは完全に独立**して処理される。

```
呼び出し A: フレーム 0〜49  → 独自スケールで深度推定
呼び出し B: フレーム 50〜99 → 別の独自スケールで深度推定
                 ↑
           バッチ間でスケールがずれる（スケールドリフト）
```

### 対処: `da3_streaming/`

`da3_streaming/da3_streaming.py` はこの問題に対処するためのモジュールで、以下を行う：

1. **チャンク間アライメント**：隣接チャンクの点群を重ね合わせ、SIM(3) 変換（スケール・回転・並進）で整合させる
2. **ループクロージャ検出**：SALAD により視覚的に類似する遠隔フレームを探し、累積誤差を補正する
3. **グローバル最適化**：ループ拘束を含む全チャンクのポーズをグラフ最適化で一括精緻化する

---

## まとめ

| 状況 | フレーム間の一貫性 |
|------|-------------------|
| 同一 `inference()` 呼び出し（N フレーム一括） | ✅ 保証される（Global attention による相互参照） |
| 複数回 `inference()` を呼び出す（バッチ分割） | ❌ 保証されない（スケールドリフトあり） |
| `da3_streaming/` を使う | ✅ SIM(3) アライメントとループ補正で事後的に整合 |
